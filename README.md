**Bracelet Supreme - An E-Commerce Website**

A fully functional e-commerce platform for selling bracelets online with a complete admin management system.

**Features**

**Customer** **Features**

1. Fully responsive design (mobile, tablet, desktop)

**Admin** **Features**

1. Add new products with images and details
2. Edit existing product information
3. Delete products from inventory

**Technologies** **Used**

1. **Frontend**: HTML5, CSS3, JavaScript
2. **Framework**: Bootstrap
3. **Design**: Responsive, mobile-first approach
4. **Icons**: Font Awesome / Bootstrap Icons
